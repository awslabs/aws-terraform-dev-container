## Security

We take the security of our software products and services seriously, including all source code repositories managed through our GitHub organizations.

If you discover a potential security issue in this project, please notify AWS/Amazon Security via our [vulnerability reporting page](http://aws.amazon.com/security/vulnerability-reporting/) or directly via email to [aws-security@amazon.com](mailto:aws-security@amazon.com). Please do **not** create a public GitHub issue for security reports.

Thank you for helping keep our users safe.
